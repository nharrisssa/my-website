# Personal Portfolio

A complete, responsive one-page portfolio built with plain HTML, CSS, and JavaScript. It includes a hero, about section, selected projects, and a contact form in a modern blue visual theme.

## Run locally

No build process or dependencies are required. Open `index.html` directly in a browser, or start a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

- Replace the name, biography, location, statistics, and project descriptions in `index.html`.
- Update `hello@alexmorgan.dev` in both `index.html` and `script.js`.
- Replace the placeholder LinkedIn and GitHub URLs in the footer.
- Adjust the main colors through the custom properties at the top of `styles.css`.

The contact form uses a `mailto:` link, so it works without a back end and opens the visitor’s default email application.
